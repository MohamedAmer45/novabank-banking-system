# NovaBank Banking System

NovaBank is a full-stack simulated digital banking application designed for
software quality engineering and testing practice.

## Architecture

The rebuilt application will use:

- Static HTML/CSS/JavaScript frontend
- Node.js backend
- PostgreSQL persistent database
- Stateless JWT authentication
- MFA simulation
- REST APIs
- Vercel deployment

## QA Repository

The test automation project is maintained separately in:

qa-banking-system

## Important

This is a simulated banking environment.

No real money, cards, or external banking networks are used.
